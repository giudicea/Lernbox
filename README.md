# Lernbox

Formelsammlung die ständig erweitert wird.

## Elektro-Toolbox

Ein Planungs- und Rechentool für Elektriker/Profis nach Schweizer Normen (NIN / SN 411000, EN 12464-1):

- **Kabelquerschnitt** — Querschnitt nach Strombelastbarkeit + Spannungsfall, alle Verlegearten (A1/A2/B1/B2/C/D1/D2/E/F), wählbare Absicherung
- **Magnetismus** — Durchflutung, Feldstärke, Flussdichte, Fluss, Spulendraht-Länge
- **Beleuchtung** — Lichtstromverfahren nach EN 12464-1, kuratierte Raumnutzungen
- **Formelsammlung** — Wärmemenge, Innenwiderstand, Pumpleistung, Energiekosten, Temperaturwiderstand, Trigonometrie — jeweils mit eigenen Werten berechenbar

Der Code liegt in [`site/`](site/) als reines statisches HTML/CSS/JS (kein Build-Schritt nötig) und wird per GitHub Actions automatisch auf GitHub Pages veröffentlicht, sobald `site/` sich ändert.
